课表配置编辑器

可视化编辑课表 · Excel 批量导入导出 · 一键生成 js/config.js

使用说明： ① 直接在网页里改各项配置；② 或点「导出 Excel」下载表格，在 Excel 里批量填好后点「导入 Excel」回传； ③ 全部改完点「导出 config.js」下载文件，覆盖到课表网站的 js/config.js 即可生效。 日期支持 2026-09-07 / 2026.9.7 / 2026年9月7日 / 20260907； 时间支持 8:40 / 08:40 / 8：40 / 8点40分。
